# Transcripción de NVDA (extracto)

NVDA 2026.2 portable en Windows 11 con Microsoft Edge, sintetizador silencioso y registro a nivel
entrada/salida (`-l 12`). Lo que sigue son las líneas que NVDA anunció, en orden, quitando el ruido del
propio navegador. Los registros completos quedan en el banco de auditoría (`nvda/nvda-sesion*.log`).

Sitio bajo prueba: build de producción servido en una subruta (`/zibata-comer-y-beber/`), igual que en
GitHub Pages.
